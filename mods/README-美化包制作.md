# 🎨 美化包（Mod）制作指南

**一句话：建个文件夹，扔几张图进去，游戏里选一下就能用。**

---

## 一、目录结构

```
game/mods/
  └─ 我的美化包/            ← 文件夹名随便起（会显示在游戏的设置里）
       pack.json            ← 配置文件（可以不要，会自动生成默认的）
       background.png       ← 游戏背景（可选）
       cardback.png         ← 对手手牌的卡背（可选）
       logo.png             ← 左上角标题图（可选，一般不用）
       frame.png            ← 面板边框装饰（可选，九宫格拉伸）
```

**最少只要一张图就能叫一个美化包** —— 缺什么就用游戏默认的。

---

## 二、每个文件的要求

### 🖼 background.png —— 游戏背景
```
推荐尺寸：1920 × 1080（或更大的 16:9）
格式：      PNG / JPG / WebP
说明：      会铺满整个页面。建议**中间偏暗**（因为卡牌面板压在中间）
           如果图很亮，游戏会自动在上面加一层半透明遮罩（可在 pack.json 关掉）
```

### 🎴 cardback.png —— 对手手牌背面
```
推荐尺寸：300 × 400（竖版 3:4）
格式：      PNG / JPG / WebP
说明：      每一张对手手牌都用这张图当底
           会按卡片大小自动缩放（可能裁边），所以主体别太靠边
```

### 🏷 logo.png —— 左上角标题
```
推荐尺寸：400 × 120（横版，透明背景最好）
说明：      替换「🎴 卡牌对决」那几个字。不设置就保留文字
```

---

## 三、pack.json（配置文件，可选）

```json
{
  "name": "我的美化包",
  "author": "你的名字",
  "version": "1.0",
  "desc": "星空主题",
  "overlay": 0.35,
  "blur": 0,
  "tags": ["night", "blue"]
}
```

| 字段 | 含义 | 默认值 |
|---|---|---|
| `name` | 显示名字 | 文件夹名 |
| `author` | 作者 | 空 |
| `desc` | 一句话简介 | 空 |
| `overlay` | 背景上的暗色遮罩强度（0~0.9） | `0.25` |
| `blur` | 背景模糊像素（0~20） | `0` |
| `tags` | 标签（暂时只是记录） | `[]` |
| `hideBokeh` | 是否隐藏游戏自带的糖果色圆点背景 | `false` |

**不要 pack.json 也行**，会用全默认值 + 文件夹名当名字。

---

## 四、怎么做最快

```
① 打开文件夹：game\mods\
② 新建文件夹，比如 "夜空"
③ 把一张 16:9 的图拖进去，改名成 background.png
④ 把一张 3:4 的图拖进去，改名成 cardback.png
⑤ 刷新游戏页面 → 点 ⚙️ → 美化包 → 选「夜空」
⑥ 完成
```

---

## 五、几个建议

```
· 背景别太花 —— 卡牌面板会盖住中间一大片，太花会看不清牌
· 卡背主体放中间 —— 会被裁边
· 可以用同一个主题的图做一套（比如都是星空、都是樱花、都是赛博）
· 图别太大：背景 3MB 以内、卡背 500KB 以内，加载快
```
