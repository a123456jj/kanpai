🔬 对比实验：外框在动 vs 图本身在动

左边是"把整张图当一块砖，移动它"（我前面做的）· 右边是"**改造图片内部的像素**"（用 Python 逐帧重算 24 张，做成 APNG）

❌ A · 外框动（整张图当砖头搬） 图本身 0 像素改变

整张图在容器里 translateY 上下浮动 + rotate 轻摇。
图里的像素一个都没变 —— 头发没飘、灯没亮、星星没闪。所以你看着总觉得"只是框在晃"。

✅ B · 图本身动（逐像素改造） 每一帧都重算了像素

用 Python 把这张图**重算了 24 次**，做成 APNG（浏览器直接动）：
① 头发区域逐像素正弦位移（越往下飘得越多）
② 胸口纵向非等比缩放（呼吸）
③ 天上 32409 个"星星像素"各自闪烁
④ 两盏路灯区域亮度脉动
⑤ 红礼盒粉色光晕呼吸
⑥ 尘埃直接写进像素里
⑦ RGB 通道错位（色散）
帧间平均像素差 10.23 —— 证明是图自己在变。

📊 到底什么能变、什么不能变

效果能做吗原理
头发飘动能把头发区域的像素按正弦波**平移**（逐像素重采样），不是"长出新的头发"
呼吸起伏能胸口区域纵向拉伸 1.2%，本质是像素被拉长
星星闪烁 / 灯亮呼吸能在选定区域叠加亮度（改像素值）
水面倒影晃动能镜像 + 横向波浪位移
整张图扭曲 / 液化能位移场扭曲，像素搬家
眨眼勉强把眼睛区域压扁 + 用肤色盖住 → 能"闭"，但会露出补丁痕迹
抬手 / 转头 / 换姿势不能这些姿势的像素**原本不存在**，我没法凭空画出来
她走路 / 转身离开不能需要新画面（序列帧 / 骨骼动画 / 3D 模型）
一句话总结：我能让图里的**像素搬家 / 拉伸 / 变亮变暗**（所以头发会飘、会呼吸、会闪）； 但我**不能创造不存在的像素**（所以抬不了手、转不了头）。
想要真动作 → 需要同场景的 2~3 张不同姿势图，我做帧间交叉 + 局部补间。
